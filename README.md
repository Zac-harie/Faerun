Petit jeu en Java qui tourne sur l'invité de commande. 
Prend place dans un monde fantastique, les 4 unités disponibles sont les nains, le chef nain, les elfes et le chef elfes.
Le but est d'entrainé des unités qui vont avancer sur un plateau unidimensionnel. 
Un combat se lancera quand 2 unités ennemies seront sur des cases adjacentes.
Le jeu se finit quand les unités arrivent au chateau adverse.
